# Maintenance Documents

## Purpose

This directory stores project maintenance records that are useful for auditing but are not primary user-facing documentation.

## Files

- `PROGRESS.md`: historical session progress and phase notes.
- `VERIFICATION_CHECKLIST.md`: verification checklist and validation evidence.
- `DOCUMENTATION_CLEANUP_REPORT.md`: documentation cleanup decisions.
- `SECURITY_FIXES.md`: security fix matrix and rollback notes.

## Boundaries

- Current project entrypoints live in `README.md`, `readme_cn.md`, and `docs/DOCS_INDEX.md`.
- Current API and release state live in `docs/API_CONTRACT_CURRENT.md` and `docs/RELEASE_READINESS.md`.
- This directory is not the default onboarding path; it is an audit shelf.
